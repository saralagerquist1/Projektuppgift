# Mormors Café

Detta projekt är en webbplats för det fiktiva företaget Mormors Café. Syftet med webbplatsen är att presentera caféets verksamhet och förmedla en nostalgisk och hemtrevlig känsla inspirerad av svensk fikakultur.

## Tekniker

- HTML – webbplatsens struktur.
- CSS – design och responsiv layout.
- JavaScript – interaktiva funktioner.

## Funktioner

- Information om caféet och dess historia.
- Interaktiv lunchmeny där besökaren kan bläddra mellan tre dagar.
- Kontaktformulär med kontroll av obligatoriska fält.
- Responsiv design för mobil, surfplatta och dator.
